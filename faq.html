MAREA · FAQ

Guía de criterios de evaluación

Explicación de cada pregunta de la herramienta MAREA y orientación para seleccionar cada respuesta.

Cómo usar esta guía

Esta página explica los criterios de la herramienta MAREA. Para cada pregunta se indica qué evalúa y en qué casos debe seleccionarse cada respuesta. La guía no sustituye la revisión experta cuando existan licencias propias, condiciones ambiguas o información no verificable.

Las opciones No aplica deben utilizarse solo cuando el criterio no corresponde a la naturaleza del recurso. No deben usarse para casos en los que el criterio sí aplica, pero no se ha comprobado o no se cumple.

Comprueba si el recurso puede reconocerse, citarse y contextualizarse correctamente.

1. ¿El recurso se identifica claramente como un REA?

Valora si el propio recurso declara de forma explícita que es un recurso educativo abierto o equivalente.

Respuesta Cuándo seleccionarla
Sí Cuando se indica claramente que es un REA o recurso educativo abierto.
Parcialmente Cuando se sugiere apertura, pero sin usar una denominación clara o inequívoca.
No Cuando no aparece ninguna indicación sobre su condición de REA.

2. ¿Se identifica el tipo de recurso? (p. ej., guía docente, vídeo, actividad)

Valora si se informa de la naturaleza del material para facilitar su interpretación y reutilización.

Respuesta Cuándo seleccionarla
Sí Cuando el tipo de recurso aparece claramente identificado.
Parcialmente Cuando puede deducirse, pero no se declara de forma explícita.
No Cuando no se puede saber con claridad qué tipo de recurso es.

3. ¿Se identifica el nivel académico?

Permite saber para qué etapa, curso, ciclo o nivel educativo está pensado el recurso.

Respuesta Cuándo seleccionarla
Sí Cuando el nivel académico está indicado de forma clara.
Parcialmente Cuando se aporta alguna pista, pero el nivel no queda delimitado.
No Cuando no aparece información sobre el nivel educativo.

4. ¿Se indica claramente la edición, versión y fecha de publicación, actualización o revisión?

Valora la trazabilidad temporal del recurso y permite saber si se trata de una versión vigente.

Respuesta Cuándo seleccionarla
Sí, de forma completa Cuando se indican versión o edición y fecha de publicación, actualización o revisión.
Parcialmente Cuando solo aparece alguno de esos datos.
No Cuando no hay información suficiente sobre versión o fechas.

5. ¿Se indica si el recurso es original, adaptación, traducción o remezcla de otro recurso?

Ayuda a conocer la procedencia del material y a comprobar atribución, licencias y compatibilidad de reutilización.

Respuesta Cuándo seleccionarla
Sí Cuando se declara claramente si el recurso es original, adaptación, traducción o remezcla.
Parcialmente Cuando se menciona alguna procedencia, pero no queda suficientemente clara.
No Cuando no se informa sobre el origen del recurso.
No se puede determinar Cuando la información disponible no permite verificarlo.

Evalúa las condiciones jurídicas y de acceso que permiten considerar el recurso como abierto.

1. ¿El acceso al recurso es gratuito?

Comprueba si cualquier persona puede acceder al recurso sin pago directo.

Respuesta Cuándo seleccionarla
Sí Cuando el recurso puede consultarse gratuitamente.
Parcialmente Cuando parte del recurso es gratuita, pero otra parte exige pago o acceso restringido.
No Cuando el acceso requiere pago. Esta respuesta activa una condición excluyente.

2. ¿El recurso exige registro o recogida de datos personales?

Valora si existen barreras de acceso derivadas de identificación, registro o entrega de datos.

Respuesta Cuándo seleccionarla
No Cuando el recurso se consulta sin registro ni entrega de datos personales.
Sí, opcional Cuando el registro existe, pero no es necesario para acceder al recurso.
Sí, obligatorio Cuando el acceso exige registro o recogida de datos. No excluye automáticamente, pero reduce la apertura efectiva.

3. ¿El recurso puede descargarse o conservarse localmente?

Se relaciona con la posibilidad de retener una copia del recurso y reutilizarla en otros contextos.

Respuesta Cuándo seleccionarla
Sí Cuando puede descargarse o guardarse localmente de forma completa.
Parcialmente Cuando solo se puede descargar una parte o en condiciones limitadas.
No Cuando solo puede consultarse en línea y no puede conservarse localmente.

4. ¿Bajo qué licencia se distribuye el recurso?

Identifica los permisos legales de uso, adaptación y redistribución. Es uno de los criterios centrales de conformidad REA.

Respuesta Cuándo seleccionarla
Dominio público / CC0 Cuando el recurso está en dominio público o se renuncia a derechos patrimoniales mediante CC0.
CC BY / CC BY-SA Cuando se permite reutilizar, adaptar y redistribuir con atribución, y en BY-SA manteniendo la misma licencia.
CC BY-NC / CC BY-NC-SA Cuando se permite reutilizar y adaptar, pero con restricción de uso comercial.
CC BY-ND / CC BY-NC-ND Cuando se prohíben obras derivadas. Esta respuesta activa una condición excluyente.
GNU Free Documentation License, sin secciones invariantes Cuando se trata de documentación y la licencia permite copia, modificación y redistribución.
GNU GPLv3 / MIT / Apache-2.0 / BSD Cuando el recurso es software o código fuente.
Licencia institucional, educativa u otra abierta que permite explícitamente las 5R Cuando el texto de la licencia permite retener, reutilizar, revisar, remezclar y redistribuir.
Licencia institucional, educativa u otra no verificable Cuando no se puede confirmar automáticamente que permite las 5R. Requiere revisión manual.
Todos los derechos reservados Cuando no se conceden permisos abiertos suficientes. Esta respuesta activa una condición excluyente.
Sin licencia indicada Cuando no aparece licencia. Esta respuesta activa una condición excluyente.

5. ¿La licencia está indicada de forma visible junto al recurso?

Valora si los usuarios pueden conocer los permisos sin buscar información externa o ambigua.

Respuesta Cuándo seleccionarla
Sí Cuando la licencia aparece junto al recurso o en una zona claramente visible.
Parcialmente Cuando la licencia aparece en una página general, pie, repositorio o documento separado.
No Cuando no se muestra una licencia visible asociada al recurso.

6. ¿Qué grado de ejercicio de las 5R permite el recurso? (retener, reutilizar, revisar, remezclar y redistribuir)

Resume si la licencia y las condiciones técnicas permiten ejercer las cinco acciones básicas de apertura.

Respuesta Cuándo seleccionarla
Permite las 5R sin restricciones relevantes Cuando se pueden ejercer las cinco acciones sin barreras jurídicas o técnicas importantes.
Permite las 5R con restricción NC Cuando se permiten las 5R, pero se restringen usos comerciales.
Permite algunas 5R, pero no revisión/remezcla por ND Cuando la licencia contiene ND. Esta respuesta activa una condición excluyente.
No permite las 5R (por cualquier motivo, principalmente, licencia cerrada o ausencia de licencia) Cuando no se pueden ejercer las acciones básicas de apertura, especialmente por licencia cerrada o ausencia de licencia.
No las permite por DRM o bloqueo técnico severo Cuando hay restricciones técnicas que impiden ejercer derechos de reutilización.
No se puede determinar Cuando la información disponible no permite verificarlo. Requiere revisión manual.

Analiza si la apertura jurídica puede ejercerse técnicamente mediante descarga, edición, portabilidad y modularidad.

1. ¿El recurso está disponible en un formato abierto?

Valora si el archivo o soporte usa formatos documentados, interoperables y no dependientes de una herramienta propietaria concreta.

Respuesta Cuándo seleccionarla
Sí Cuando está disponible en formatos abiertos o ampliamente interoperables.
Parcialmente Cuando existe alguna versión abierta, pero no es la principal o no cubre todo el recurso.
No Cuando solo se ofrece en formatos cerrados o dependientes de software propietario.

Ver ejemplos de formatos para cada caso

Sí: formatos abiertos, interoperables y documentados

HTML, XHTML, XML, Markdown, TXT, CSV, TSV, JSON, JSON-LD, RDF/XML, Turtle, N-Triples, RDFa, YAML, ODT, ODS, ODP, ODG, EPUB sin DRM, LaTeX, BibTeX, RIS, SVG, PNG, JPEG/JFIF, WebP, TIFF, GeoJSON, GML, GPX, KML, NetCDF, HDF5, WAV, FLAC, Ogg Vorbis, Opus, Ogg Theora, WebM, Matroska, WebVTT, SRT, TTML, IMS Common Cartridge, IMS QTI, H5P exportable y paquetes ZIP que contengan archivos abiertos.

Parcialmente: formatos estandarizados o ampliamente interoperables, pero con límites de edición, dependencia de software o pérdida de estructura

PDF, PDF/A, DOCX, XLSX, PPTX, RTF, MP3, MP4/H.264, AAC, MOV, paquetes SCORM, presentaciones o documentos exportados desde plataformas, imágenes rasterizadas de materiales textuales, copias escaneadas con OCR, archivos comprimidos con mezcla de formatos abiertos y cerrados, y recursos que ofrecen un formato abierto solo como copia secundaria.

No: formatos cerrados, bloqueados o dependientes de una aplicación o plataforma concreta

INDD, PSD cuando no se acompaña de fuentes abiertas, AI cuando exige software propietario para editar, FLA, SWF, PUB, QXD, CPTX, STORY, NOTEBOOK, FLIPCHART, Pages, Keynote, Numbers cuando no hay exportación abierta, AZW, KFX, libros electrónicos con DRM, ejecutables EXE/APP/APK cerrados, contenidos solo en streaming sin descarga, actividades alojadas únicamente en plataformas sin exportación, documentos protegidos con contraseña o restricciones de copia, y cualquier formato cuyo uso real dependa de una herramienta propietaria o de un servicio cerrado.

2. ¿El recurso es editable?

Evalúa si el material puede modificarse de forma razonable para adaptarlo, traducirlo o remezclarlo.

Respuesta Cuándo seleccionarla
Sí Cuando se ofrecen archivos fuente o formatos editables.
Parcialmente Cuando se puede editar con limitaciones o solo en parte.
No Cuando el recurso no puede modificarse de forma práctica.

3. ¿El recurso está organizado en partes reutilizables?

Valora si el recurso puede reutilizarse por módulos, fragmentos o unidades independientes.

Respuesta Cuándo seleccionarla
Sí Cuando la estructura facilita extraer y reutilizar partes del recurso.
Parcialmente Cuando algunas partes son reutilizables, pero la estructura general no lo facilita del todo.
No Cuando el recurso es monolítico o difícil de separar en unidades reutilizables.

4. ¿El recurso puede usarse sin depender de una plataforma concreta?

Comprueba si el uso del recurso no queda bloqueado por una plataforma específica, cuenta cerrada o entorno técnico único.

Respuesta Cuándo seleccionarla
Sí Cuando el recurso puede usarse fuera de la plataforma original.
Parcialmente Cuando parte del recurso puede usarse fuera, pero alguna funcionalidad depende de la plataforma.
No Cuando el recurso solo funciona dentro de una plataforma concreta.
No se puede determinar Cuando no hay información suficiente para comprobarlo.

Comprueba si el recurso está suficientemente descrito para facilitar su localización, citación, interpretación y reutilización educativa.

1. ¿Qué metadatos descriptivos básicos incluye?

Selecciona todos los elementos descriptivos presentes en el recurso, su ficha o su repositorio.

Respuesta Cuándo seleccionarla
Título Seleccionar si el recurso tiene un título identificable.
Autoría Seleccionar si se indica persona, entidad o equipo responsable.
Fecha Seleccionar si se indica publicación, actualización o revisión.
Idioma Seleccionar si se declara el idioma del recurso.
Descripción Seleccionar si existe resumen o explicación del contenido.
Palabras clave / Materias Seleccionar si se incluyen términos temáticos o materias.
Tipo Seleccionar si se indica la clase de recurso.
Licencia Seleccionar si la licencia aparece como metadato o dato descriptivo.

2. ¿Qué metadatos educativos incluye?

Selecciona todos los datos que ayuden a reutilizar el recurso en un contexto docente.

Respuesta Cuándo seleccionarla
Nivel Seleccionar si se indica etapa, ciclo, curso o nivel académico.
Destinatarios Seleccionar si se especifica el público al que va dirigido.
Objetivos Seleccionar si se explican los objetivos de aprendizaje.
Competencias Seleccionar si se indican competencias o resultados esperados.
Tiempo estimado Seleccionar si se informa de duración o carga de trabajo.
Contexto de uso Seleccionar si se explica cómo o dónde utilizar el recurso.
Requisitos previos Seleccionar si se indican conocimientos, materiales o condiciones previas.
Otros metadatos educativos Seleccionar si se incluyen otros datos educativos relevantes no recogidos en las opciones anteriores.

3. ¿El idioma principal del recurso está declarado correctamente?

Valora si el idioma está indicado de forma clara y coherente con el contenido.

Respuesta Cuándo seleccionarla
Sí Cuando el idioma principal está declarado correctamente.
Parcialmente Cuando se declara de forma incompleta o poco precisa.
No Cuando no se declara o se declara de forma errónea.
No se puede determinar Cuando no hay información suficiente para verificarlo.

Evalúa condiciones básicas para que el recurso pueda ser utilizado por personas con diferentes capacidades, tecnologías de apoyo y contextos de acceso.

1. ¿El recurso cuenta con una estructura visual y semántica mediante títulos, subtítulos u otros elementos estructurales?

Comprueba si el contenido está organizado con encabezados, listas, secciones, marcadores u otros elementos que faciliten la navegación.

Respuesta Cuándo seleccionarla
Sí Cuando la estructura es clara visual y semánticamente.
Parcialmente Cuando existe estructura visual, pero no siempre es semántica o consistente.
No Cuando el contenido carece de estructura clara.
No aplica Cuando la naturaleza del recurso no requiere estructura textual o documental.

2. ¿El contenido no textual cuenta con una alternativa de texto?

Valora si imágenes, gráficos, iconos informativos u otros elementos no textuales tienen alternativa textual.

Respuesta Cuándo seleccionarla
Sí Cuando todo contenido no textual relevante tiene alternativa adecuada.
Parcialmente Cuando solo algunos elementos la tienen o la alternativa es insuficiente.
No Cuando no se proporcionan alternativas.
No aplica Cuando el recurso no contiene contenido no textual relevante.

3. ¿Los materiales audiovisuales cuentan con subtítulos, transcripciones o alternativas equivalentes?

Comprueba si audio y vídeo ofrecen alternativas para quienes no pueden o no quieren reproducir sonido o imagen.

Respuesta Cuándo seleccionarla
Sí Cuando todos los materiales audiovisuales tienen subtítulos, transcripción o alternativa equivalente.
Parcialmente Cuando solo algunos materiales la tienen o es incompleta.
No Cuando no se ofrecen alternativas.
No aplica Cuando el recurso no contiene audio ni vídeo.

4. ¿El recurso evita depender solo del color, la forma o la posición para transmitir información?

Evalúa si la información se transmite también mediante texto, etiquetas, patrones u otros indicios redundantes.

Respuesta Cuándo seleccionarla
Sí Cuando la información no depende únicamente de color, forma o posición.
Parcialmente Cuando hay algunos casos problemáticos, pero no afectan a todo el recurso.
No Cuando información importante solo se transmite por color, forma o posición.

5. ¿El contraste entre el texto y el fondo y entre elementos no textuales es suficiente?

Valora si los elementos visuales se distinguen con claridad para favorecer la lectura y percepción.

Respuesta Cuándo seleccionarla
Sí Cuando el contraste es suficiente en todo el recurso.
Parcialmente Cuando hay algunos elementos con contraste insuficiente.
No Cuando el contraste es insuficiente de forma general o en elementos clave.
No comprobado Cuando no se ha verificado el contraste.

6. ¿El recurso es compatible con ayudas técnicas, incluidas las que permiten personalizar los estilos del documento?

Comprueba si el recurso funciona con lectores de pantalla, navegación asistida o ajustes personalizados de visualización.

Respuesta Cuándo seleccionarla
Sí Cuando se ha comprobado compatibilidad y no hay bloqueos relevantes.
Parcialmente Cuando algunas partes son compatibles, pero existen limitaciones.
No Cuando el recurso presenta barreras importantes para ayudas técnicas.
No comprobado Cuando no se ha evaluado la compatibilidad.

7. ¿El texto puede ampliarse hasta el 200 % sin pérdida de contenido o funcionalidad?

Valora si el recurso mantiene contenido y funciones al aumentar el tamaño del texto.

Respuesta Cuándo seleccionarla
Sí Cuando el texto puede ampliarse hasta el 200 % sin solapamientos, cortes o pérdida de funciones.
No Cuando al ampliar el texto se pierde contenido, se rompe la interfaz o dejan de funcionar elementos.
No aplica Cuando el recurso no contiene texto ampliable o el criterio no corresponde a su naturaleza.

8. ¿El recurso permite ajustar interlineado, espaciado entre párrafos, letras y palabras sin pérdida de contenido?

Comprueba si los ajustes de espaciado no provocan pérdida de contenido o funcionalidad.

Respuesta Cuándo seleccionarla
Sí Cuando el contenido soporta cambios de espaciado sin pérdida ni solapamiento.
No Cuando esos ajustes rompen la lectura, ocultan contenido o afectan a funciones.
No aplica Cuando el recurso no contiene texto susceptible de estos ajustes.

9. ¿Todas las funciones del recurso pueden usarse con teclado?

Valora si la interacción principal no depende exclusivamente del ratón, gestos o puntero.

Respuesta Cuándo seleccionarla
Sí Cuando todas las funciones se pueden activar y completar con teclado.
No Cuando alguna función esencial no es accesible mediante teclado.
No aplica Cuando el recurso no contiene funciones interactivas.

10. Si hay límites de tiempo, ¿pueden desactivarse, ajustarse o ampliarse?

Comprueba si los usuarios tienen tiempo suficiente para leer, interactuar y completar tareas.

Respuesta Cuándo seleccionarla
Sí Cuando el límite puede desactivarse, ajustarse o ampliarse antes de agotarse.
No Cuando existe límite de tiempo y no se ofrece control suficiente al usuario.
No aplica Cuando no hay límites de tiempo.

11. ¿Se explica el significado de las abreviaturas utilizadas?

Valora si las abreviaturas, siglas o acrónimos se desarrollan o explican cuando pueden dificultar la comprensión.

Respuesta Cuándo seleccionarla
Sí Cuando las abreviaturas se explican la primera vez o mediante un mecanismo claro.
No Cuando se usan abreviaturas relevantes sin explicación.
No aplica Cuando no se usan abreviaturas o son innecesarias para comprender el recurso.

12. Si hay formularios, ¿los errores se identifican y describen con texto?

Comprueba si los formularios informan textualmente de los errores y del campo afectado.

Respuesta Cuándo seleccionarla
Sí Cuando los errores se identifican y describen con mensajes claros.
No Cuando los errores no se indican, solo se marcan visualmente o no se describen.
No aplica Cuando el recurso no contiene formularios.

13. ¿El recurso evita destellos o efectos visuales que puedan provocar convulsiones o reacciones físicas?

Valora si el diseño evita parpadeos, destellos intensos o efectos que puedan causar reacciones físicas.

Respuesta Cuándo seleccionarla
Sí Cuando no se usan destellos o efectos visuales de riesgo.
No Cuando existen destellos, parpadeos o efectos potencialmente problemáticos.
No aplica Cuando el recurso no contiene contenido visual dinámico.

Valora si el recurso está publicado en un entorno estable y puede ser citado o localizado de forma persistente.

1. ¿Está publicado en un repositorio o plataforma estable?

Comprueba si el recurso está alojado en un entorno que favorece su disponibilidad, mantenimiento y preservación.

Respuesta Cuándo seleccionarla
Sí, repositorio Cuando está en un repositorio institucional, temático o de confianza.
Sí, plataforma estable Cuando está en una plataforma con estabilidad razonable.
Web institucional o personal Cuando está en una web identificable, pero sin garantías claras de preservación.
Plataforma externa Cuando depende de un servicio externo con menor control institucional.
Campus o entorno cerrado Cuando solo está disponible en un entorno de acceso restringido.
No Cuando no hay publicación estable identificable.

2. ¿El recurso cuenta con una URL estable o identificador persistente?

Valora si el recurso puede citarse y recuperarse mediante una dirección estable.

Respuesta Cuándo seleccionarla
DOI Cuando dispone de DOI.
Handle Cuando dispone de Handle.
URI permanente Cuando dispone de URI persistente.
URL estable Cuando existe una URL razonablemente estable, aunque no sea identificador persistente.
URL no persistente Cuando la URL parece temporal, dependiente de sesión o poco estable.
No Cuando no hay URL estable ni identificador persistente.

Criterio general

MAREA evalúa conformidad formal: licencia, acceso, reutilización técnica, metadatos, accesibilidad y publicación. No evalúa la calidad científica, pedagógica o disciplinar del contenido.
